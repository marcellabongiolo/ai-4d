# AI 4D — Product Direction

## Hipótese

Pessoas e equipes que trabalham com dados que mudam ao longo do tempo podem se beneficiar de uma interface simples que transforme séries temporais em visualizações, tendências e previsões.

## Primeiro usuário

Ainda não está validado. A V2 é um protótipo de produto para testar a experiência e descobrir quais problemas têm valor real.

## Proposta experimental

**Dados → análise temporal → visualização → sinal interpretável**

## Não é

- uma previsão garantida;
- uma ferramenta médica ou financeira;
- uma plataforma de IA pronta para produção;
- evidência de que existe demanda comercial validada.

## Métricas futuras

- número de análises concluídas;
- tempo até o primeiro insight;
- retenção;
- qualidade das previsões;
- feedback dos usuários;
- disposição real para pagar.

## Próxima decisão

Depois de testar a V2, escolher um caso de uso específico com base em evidências, em vez de presumir qual mercado deve ser atendido.
